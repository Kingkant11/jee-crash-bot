### Step 2: Setup & Test Locally (30 minutes)

**Option A: Your Laptop**
```bash
# Navigate to project
cd ~/jee-bot

# Install dependencies
npm install

# Create .env file
cp .env.example .env

# Edit .env with your keys
nano .env

# Paste your keys and save (Ctrl+X, Y, Enter)

# Start bot
npm start
```

You should see:
```

📊 Bot: @your_bot_username
✅ Waiting for users...
```
